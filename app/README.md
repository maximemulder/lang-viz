# Language Atlas frontend

Static React client for exploring the geographic distribution and relationships of
the world's languages.

## Development

Requires Node.js 24 or newer and Python 3 (for the local lexical-data build).

```sh
npm install
npm run dev
```

Other useful commands:

```sh
npm run typecheck
npm run check
npm run build
npm run test:browser
```

See [browser checks and measurements](tests/browser/README.md) for requirements,
repeatable scenarios, output artifacts, and visible-browser runs.

The initial basemap uses EOX terrain tiles and needs an internet connection. Language
geometry will be generated by the repository's offline data pipeline and loaded as
static vector tiles.

## Etymology workspace

**Word histories** is a native React feature with word-history graphs, concept
comparison, and separate word/relationship references. Its DiACL dataset builds
automatically before development, tests, and production builds; run
`npm run data:etymology` to generate it explicitly. It needs only the local exports
in `../etymology/data/`, not the geographic pipeline or an external API.

**Show on atlas** uses the existing MapLibre map for lexical focal points and
connections. **Add matched language areas** respects the current geography filters;
pinned map inspectors link back to lexical entries. See the
[integration notes](../etymology/README.md) for identifier matching, data semantics,
architecture, and limitations.
